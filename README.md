# Telegram Ad Earning Bot

A starter Telegram bot for an ad/offer earning system.

## Required environment variables

- `BOT_TOKEN` — Telegram BotFather token
- `ADMIN_ID` — your numeric Telegram user ID

## Important

Do not put your Bot Token inside this repository. Use your hosting provider's secret/environment-variable settings.

The ad section is intentionally prepared for later integration with a legitimate ad/offer provider. Do not credit users merely for clicking a fake “completed” button; real rewards should be confirmed by the provider's supported tracking/callback system.

Withdrawals are manual bKash/Nagad requests in this starter version.
